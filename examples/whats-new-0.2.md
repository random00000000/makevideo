# What's new in makevideo 0.2
Premium by default
> Here is what is new in makevideo, version zero point two.

## The goal
Premium videos on the *first try*.
> The goal of this release: a premium video, on the very first try.

## Real transitions
- Push, slide, zoom and wipe
- Picked automatically for each scene
- Blended from the real previous frame
> Scenes now flow into each other. Push, slide, zoom, and wipe. Picked automatically for each scene. And blended from the real previous frame.

## Three new scene types
![](../docs/tiktok.mp4)
- Statement: kinetic type
- Chart: animated bars
- Split: media beside text
> There are three new scene types. Statements, with kinetic type. Charts, with animated bars. And split scenes, with media beside the text, like this one.

## Render time, 87-second video
<!-- highlight: Frame holding -->
- First build: 160 s
- Frame holding: 35 s
> Charts grow each bar as the voice reaches it. The first build took 160 s. Frame holding brought it down to 35 s.

## Write Markdown, get a video
```md
## Render time
- First build: 160 s
- Frame holding: 35 s
```
> You can now write plain Markdown. A heading over a list of numbers becomes a chart. This whole video is one Markdown file.

## Guardrails
- Symbols are read the way people say them
- Lint flags walls of text before rendering
- Bundled fonts look the same everywhere
> And guardrails make a bad video hard to make. Symbols are read the way people say them, so 42%, v1.2 and $3M just work. Lint flags walls of text before you render. And bundled fonts look the same on every machine, even a bare cloud server.
